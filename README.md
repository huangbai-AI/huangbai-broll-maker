# 黄白 Broll Maker

按口播拆配画素材表，制作录屏、动画和独立配画素材，交付编号、源文件及对词预览。

- 查看 [SKILL.md](SKILL.md)。
- 在 Codex 使用时，将仓库下载并解压，把包含 `SKILL.md` 的文件夹命名为 `huangbai-broll-maker`，复制到 `~/.codex/skills/`。重新开启对话后调用 `$huangbai-broll-maker`。
- 涉及剪映、录屏或媒体命令行工具时，按实际安装的应用和接口验证。
