# 素材生成对照表：调整与编写规范

表格让人一眼知道怎么拍、录、制作和剪辑，也让后续执行者能准确对应素材。默认三列：**阶段｜内容｜画面说明参考**。用户给了表格时保留其列名、章节顺序和合并形式；阶段可纵向合并，内容与画面说明逐行对应。

## 连续画面归组，组内按半句左右对齐

先区分两个层次：

- **画面组**：同一连续画面归在同一表格行／单元格组内。真实切镜才另起组。
- **文字行**：默认每半句口播分行，每行右侧都有对应说明。相邻两半句的画面完全一致、连续时，可以合在一行，共用一条说明；不强制每个逗号都换行。同一画面组也可包含多组对应内容，需要区分动作时继续分开。

“半句”按自然停顿和意思划分，一般到逗号、分号或一个清楚的短语；不按固定字数硬切。保留原文的字句、标点和顺序，不新增语气词、不重复半句。合行只去掉分行，不改写口播。

| 情况 | 处理 |
|---|---|
| 网页搜索、叠蒙层、蒙层消失后继续滚动 | 同一画面组；各半句分别对应搜索、蒙层、滚动等动作 |
| 同一录屏中选元素、平移到 Agent、再回预览 | 同组；左侧按半句分行，右侧相应写选中、平移输入、回看结果 |
| 同一产品视频持续播放，上面加名称、选框并调整 | 同组；新图层和新动作不等于新素材，但半句仍逐条排开 |
| 同一画面连续变为分屏，没有动作中断 | 可同组；对应半句写明构图如何连续变化 |
| 切到口播、另一作品或跳到同一文件另一时间点 | 新画面组；切点落在句中时，也按对应锚点分配口播 |
| 相邻两半句的画面一致、完全连续，共用同一说明 | 可直接合成一行；右侧只写一条对应说明 |
| 两三句由一段连续动画承载，但各半句对应不同动作或观看重点 | 同组内分别分行，动作逐条对应；不能只因使用同一文件就一概合行 |

例如“精美画面仅是基础，更重要是保证信息的准确。”两半句都连续展示同一个商业广告案例，可以合在一行，对应一条“商业广告案例展示”。“甚至我这条口播里的动效，也是用Fotor Agent加的。”若全句连续展示同一个口播动效，也可合行。是否分行取决于实际画面对应关系，不只看逗号。

右栏某条说明因列宽折成三行，而左侧半句只占一行，就在左侧该半句后补空白行，再放下一半句；使下一半句和下一条说明从相同高度开始。左侧反而更长时，右侧同样补齐。长行自动换行仍是同一条说明，不能误当成下一半句的新说明。

用真正的空白行占位，不用连续空格、全角空格或无意义字符撑位置。可在对应半句的段落末尾补换行；单独空白段落可能额外带段间距，必须按实际显示高度调整。优先精简无关说明，再补必要空行。主动作放在对应半句旁，素材名、技术细节和待补信息跟在相关说明内，不在上面挤一段总说明导致两列错位。

**两列顶端对齐不等于逐条对齐。** 在飞书实际列宽、字号和缩放下检查各组起点的高度；右栏长说明、长文件名、链接等造成的自动换行都要计入。视图宽度改变可能重新折行，应按用户参考表的常用阅读布局复核；不能仅按字符数推断对齐已通过。

保留用户已改好的章节、原台词和删除状态。若原稿被用户更新，按最新内容重排，不复活已移除的句子。

## 三种构图按表达穿插

| 表达重点 | 右栏写法与安排 |
|---|---|
| 本人的判断、反应、情绪、转折 | 【纯口播】本人是主体；可用连续轻推近强调关键判断 |
| 操作过程、作品结果或说明原理 | 【纯 B-roll｜真实录屏／说明动画／已有成片／AI 演绎】画面是主体；小圆头像仅补反应，不能挡信息 |
| 同时要看操作和本人的解释／反应 | 【上下分屏】上界面、下本人，各半；两半分别安排焦点，不能用预览＋时间轴冒充人物分屏 |

例如“本人转入新用途→具体作品→本人强调信息准确→连续动画解释组合原理→分屏展示与本人的关系→真实模板操作”。顺序由脚本内容决定，不照抄此例，不强制每段凑齐三种，不用固定秒数或行数轮换版式。强调结果时给画面足够空间，讲判断时回到本人；避免整章都是录屏或整章都是分屏。

## 右栏写到可执行

每个独立半句或符合条件的合并短句配一条简短、具体的动作说明，再按需要补必要素材信息；不要把整组动作和素材备注都挤进一个大段：

1. **构图和主角**：这个画面组选哪种组合，观众先看哪个对象。上下分屏分别指明两半的主体，仍只有一个主要叙事重点。
2. **素材与来源**：已有素材写可识别的作品／文件名和所取片段；录屏写页面与操作目标；动画写需要的底层素材和独立图层；生成视频写主体、动作与场景。素材未选定就写待选定，不能编造文件、链接、参数或产品事实。
3. **连续动作**：从什么状态开始，主体如何变化，镜头何时推近、平移、拉回，最后停在哪里；每条动作跟随其左侧半句的因果。
4. **清楚展示**：主体等比、足够大、靠近安全范围内的中心；拉开背景对比，关键文字手机可读。横屏桌面布局保持正常，竖屏通过取景适配，不拉伸、不录整页小字。
5. **结束与缺项**：哪一状态要停住让观众看清，下一行从哪里接；必要素材标待拍／待录／待生成。待补项写在对应行，不只集中在文末。

差例：“做高级 MG 动画”“展示修改过程”“多案例混合，丝滑转场”。这些句子没有说明对象、素材和具体动作。

可执行例：“【纯 B-roll｜说明动画】同一产品原片持续播放；在产品侧方依次出现准确名称和指示线，再选中名称、连续调整字号，产品本身不跳变。主体先是产品，随后是被调整的信息层；结束停在清楚的最终排版。需要产品原片、确认文案和独立 MG 图层；缺项标待补。此段是原理示意。”

表格是制作说明，不是成片字幕。能用画面和动作解释，就不默认再加标题、长字幕、报幕或多层卡片。用户明确要求的蒙层文字、模板展示等按该处指令执行，不能把局部例外推广到全片。

## 真实素材和示意的边界

- 软件操作与结果用真实录屏，优先 Ego Lite 操作、Screen Studio 保存录屏和原生运镜工程。工程效果与成片导出分别验证。
- 自写的动画解释标“原理示意”；不能画一个看似真实的软件界面，冒充平台完成了操作。
- “本条口播的动效是平台加的”等表述，必须用本条口播的真实平台工程和结果对应；没有就标待补，不能换他人案例或用外部制作效果证明。
- 纯 MG 品牌样片可以举例品牌宣传，不能凭它证明“AI 视频＋MG”的真实混合。示意组合要写清真实底层素材与独立信息层。
- 表格写收费生成需求不等于获得生成许可；制作时按实际画幅、时长、模型、声音和预计费用确认。不得擅自提交生成或改声音。

## 写入与自检

先保存源文档快照和原台词，再形成局部调整稿。新表可使用 [XML 模板](../assets/storyboard-table.xml)；模板的两行只是结构示例，按实际画面增减行、同步阶段的 rowspan，并替换全部占位文字。阶段合并用真实 rowspan，不能用重复阶段名替代用户要求的合并。

飞书操作遵循当前 lark-doc 技能。优先改目标单元格；确需增加行时查正式接口后局部插入，保留同表其余章节、附件、链接和样式。不要为改一节重建整表。写入前重读；用户正在编辑时以最新版本重新定位，发现变更应先合并用户修改再继续。依赖检查失败就停止后续写入，不能让脚本继续使用旧位置。

交付前回读，核对：

- 原台词按顺序拼回后与当前原稿相同，无缺失、重复或复活的删除内容；空白整理不改字句。
- 画面组按连续性划分；组内默认按半句分行，完全一致且连续的相邻半句可合行，右侧逐条对应。长说明后已补空白行，下一组左右起点在实际阅读布局下对齐。
- 每组都有组合方式和明确主体，每个独立半句或合并短句旁有对应说明，必要素材来源／缺项可识别，没有只有“高级、好看”的空话。
- 纯口播、纯画面与分屏按表达穿插，主体比例、对比、可读性与安全区安排清楚。
- 用户指定不改的章节、现有资源和收尾逐项比对未变；“方案已写好”与“素材已制作”分别报告。
