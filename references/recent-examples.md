# 配画案例与复用要点

同一风格先用当次授权素材做几秒小样，核对布局、运动和关键信息能否读清。在既有成片上学习时，用文字记录动作和取景，引用样片、抽帧或生成参考按当次许可处理。

| 案例方向 | 可复用的做法 | 复核位置 |
| --- | --- | --- |
| 单产品剪贴动画 | 产品、背景、纸币和前景遮挡分别整理。前景掠过时换景，后面仍保持同一件商品。 | 检查遮挡过程、包装一致及透明边缘。 |
| 产品照片环绕 | 主视觉稳定居中，照片分批环绕。用顺序和停留区分年份、照片与唱片标签。 | 重点看运动中关键文字和手机显示下的留白。 |
| 品牌排版 | 中文衬线标题与数字建立主次。商品露脸时保留品牌标识，收尾关系与上一镜连续。 | 前后对照标题、商品和视觉重心的接点。 |
| 方形画面转竖屏 | 原作品贯穿图库、手机、网页和画框。改变取景与版式时保留原比例。 | 确认同一作品、控件可读、画面填充和文字对比。 |

详细分层方法见[近期动效与分层](recent-motion-cases.md)，当次画面类型和取景要求见[构图与口播组合](framing-and-layout.md)。
