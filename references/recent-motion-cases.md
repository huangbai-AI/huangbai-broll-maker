# 近期案例与分层交付

收录日期：2026-10-23。用户认可最近案例可纳入技能；其中不同版本的动作、分层方式与限制仍须分别记录。以下是可复用的具体做法，不是把每段视频统一改成钱箱海报，也不是重新授权上传或收费生成。

## 按用途选择

| 任务 | 参考案例 | 主要借鉴 |
|---|---|---|
| 元素逐项出场、批量换风格 | 钱箱复古／现代／极简 | 背景→两行标题→钱箱的明显先后入场；不同字体、材质、版式；左到右揭示 |
| 解释视频层与可编辑信息层 | Fotor 双分支 v3 | 同一组合画面连续拆开；左侧文字、右侧真实运动的视频；关系线与标签清楚 |
| 一句话的口播包装 | 口播文字动效 v6 | 原口播对齐、大小字层级、人物前后关系、粗宋体大字的克制柔光 |
| 用户要自己继续剪素材 | Fotor 时间轴独立19素材版 | 19个图片片段、7轨，实际时间轴可见；与一条MG内部19层明确区分 |

## 一、钱箱三风格：先后出场，随后换风格

### 先设计，再拆层

同一只钱箱与同一英文标题，形成复古印刷、现代图形、极简三套设计。差异包括字形、字重、留白、纸张／图形材质，不能只换三次颜色。现有获确认设计直接复用，只有新方向才先做生图视觉探索。

每套把纸面、背景图形或柔光、接地阴影、钱箱、MAKE、BIG MOVES拆开；现代额外有装饰线，总计19层。保留相同画布与原坐标，不能把各层透明边缘裁掉后分别铺满整个画面。

拆层需核对钱箱的提手、锁扣、左前缘、箱盖和接地阴影。去背景时不要把与纸色接近的高光或金属边一起删掉。微小缺口需与原图放大对比，修局部遮罩，不反复整图生成让画面变脏。

### 可复用的入场时序

以下数字来自该案例，是调整起点，不是所有片段的固定规定。位移以941×1672素材画布为单位，换画幅要等比换算。

| 元素 | 本地开始 | 动作时长 | 动作 |
|---|---:|---:|---|
| 纸面 | 0秒 | — | 先建立画面 |
| 背景图形 | 0秒 | 0.52秒 | 84%→100%，由左54／下30归位，前0.22秒渐显 |
| MAKE | 0.12秒 | 0.52秒 | 由左40／下68归位，前0.20秒渐显 |
| BIG MOVES | 0.28秒 | 0.57秒 | 由左26／下82归位，前0.22秒渐显 |
| 现代装饰线 | 0.32秒 | 0.50秒 | 展开、归位 |
| 接地阴影 | 0.44秒 | 约0.48秒 | 配合主体淡入 |
| 钱箱 | 0.46秒 | 0.70秒 | 90%→100%，由左12／下72归位，-1.15°→0，前0.22秒渐显 |

平滑减速并落稳，不来回弹。重点是观众看得出先后次序；不能第一帧所有元素就摆好了，只给很小位移。落稳后可静止，不让文字与钱箱全程乱漂。阴影与主体动作要关联。

该长版7.5秒：复古0秒、现代1.9秒、极简4.35秒开始；1.9–2.6秒、4.35–5.05秒从左向右揭示新风格，可带克制细扫描线。新风格依次入场，不用整张静图硬切代替。短版按原时长重新计算完整动作，不用尾帧重复填充。

单独交付三种风格时，各从自己的本地0秒重新播放完整入场；本例每条2.5秒。不能直接把长版按三段切开，留下半截入场或混入上一种风格。每条标题说明对应风格与口播，保留原文件名与引用路径。

## 二、双分支：先组合，再拆解

顶部 Fotor Agent 标识，下方先展示同一个组合画面，再连续向左右展开成两个竖框。左侧说明可编辑文字，右侧显示生成视频，两支与顶部连接。标题不交叉穿过，主体保持完整。

右侧的视频内容本身必须在动：不是截一帧再让外框平移／缩放。拆分前后保持同一播放位置，避免跳回开头。若素材不足需循环／倒放，先判断动作是否合理，并保留原片、原声和说明，不把倒放说成新生成。

该案例边框由2.5增至3.75单位，是原来的1.5倍，用于增强可见性，不作为所有视频的固定描边宽度。拆分和文字变化用首尾平顺的缓动，停止处不突然刹车。沿用原点阵背景，不额外套多层卡片。

## 三、口播大字：动作与语音共同定时

按原口播逐字落点显示动效字，不能用整段平均分时长代替语音对齐。常规小字幕与大动效字承担不同观看任务；大小字是否同组排版遵循该段最新要求，不把某次修改写成所有视频的固定布局。

案例前半句大“动效”置于人物后面；后半句保留左侧半脸，Fotor 与 Agent 字间留距离，字标略向右，只被人物自然遮住少部分。大字与辅助词有清晰层级，不能把完整品牌名故意藏在头后。

“动效”最终使用粗宋体、清晰暖白字芯、轻暖色柔光；发光克制，不闪烁、不大面积铺雾。此案例v6仅修改指定第44–62帧，逐字时点、人物位置、其余画面与原音轨保留。不要据此把所有品牌字都换成宋体；Fotor Agent 字标沿用其已确认设计。

人物遮挡层必须播放检查头发、眼镜和肩部的闪边，稳定遮罩而非逐帧抖动的生图人像。推近／字标放大从开始到停止都平顺，不突然放大后僵停。只修改用户点名的字和时间段。

## 四、Fotor：独立时间轴素材与内部图层是两种交付

| 结构 | 实际编辑方式 | 可以怎样描述 |
|---|---|---|
| 一个MP4 | 只能整段剪与变换 | 合成视频 |
| 一条MG内部19个图片节点 | 在动画参数／元素列表编辑内部图层 | 内部分层动画；不能称时间轴已拆开 |
| 主时间轴19个图片片段 | 分别选择、移动、改起止、替换／删除 | 时间轴独立素材，符合本次“拆开”要求 |

本例最终是7轨19片段：纸张3、背景／柔光3、装饰线1、阴影3、钱箱3、MAKE3、BIG MOVES3。轨道可以按职责复用，不要求为了19个片段强制建19条轨道。时间轴上的转场小块不能计入19个素材。

验收要看编辑器真实时间轴，必要时上下滚动两张截图合数，再选中一个钱箱或文字，确认显示该图片自身的位置／尺寸等参数。由工程数据生成的结构图可作辅助，不能冒充实际编辑器截图。素材库有19张图也不等于时间轴已经放好。

### 该案例的限制，不能隐藏

2026-10-23该国内Fotor工程的普通图片片段只有淡入淡出及静态位置／尺寸／旋转；这次拆轨保留依次渐显，未保留单条MG里的滑入与缩放。纸张和背景轨用了两次左到右擦除，不等同于原MG对全套元素统一遮罩。**这是结构满足、动作存在差异的版本，不是完全复现。** 用户说最近案例不错，不抹去这些差异。

上述是当次实测，不是永久产品能力结论。再制作时先检查当前原生动画、关键帧、分组及拆分能力，优先在所选产品内解决。能力仍不足时可检查有依据的开源／社区实现；不要先承诺做不到，也不要把别处合成后导入当作“在Fotor里做了独立动效”。需要付费逐层重做时先算完整费用，不能只看单次费用或用旧额度默认覆盖。

含图片的工程当次导出面板最高1080P，工程4K画布不等于4K成片。实际文件记录1080×1920与真实时长。积分以项目明细核对，包含对话费；不能照抄Agent“未花生成积分”推导总费用为零，也不能把账户其他工程消耗算到本工程。
