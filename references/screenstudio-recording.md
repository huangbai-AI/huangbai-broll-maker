# Screen Studio 接入

Ego Lite 负责观察、排练和操作真实网页，Screen Studio 优先承担窗口／局部录制，以及放大、缩小、平移等展示编辑。先读[构图与口播组合](framing-and-layout.md)：横屏录对、竖屏展示清楚是两个阶段，录制成功不等于镜头完成。动效和强调层仍遵循黄白标准。

## 什么时候用

| 需要 | 通路 |
|---|---|
| 真实浏览器窗口、快速滚动、连续动画，或需要系统声音 | 优先 Screen Studio；当次检查实际画质、帧率与声音 |
| 只要无声网页内容，或当前原生录制不可用且不影响任务要求 | [Ego 连续帧录制](ego-recording.md) |
| 自己编写的代码动效，需要逐帧确定时间或原生 4K | `render-motion.mjs`，不通过录屏冒充逐帧渲染 |

使用前先发现并读取当前 `screenstudio` 技能的 `SKILL.md` 与 `references/local-setup.md`；本机入口通常为 `~/.codex/skills/screenstudio`。优先调用同名 MCP 工具。聊天未发现工具时可调用该技能的 `scripts/control.mjs`，不要复制或改写其录制引擎。换机器缺少依赖时按其安装说明处理，不把本机连接配置、授权或绝对路径放进分享包。

## 开始前

1. 先排练并把 Ego 页面置于开始状态，保存操作前快照。桌面软件保持正常横屏比例与布局，原生窗口录制前确认目标标签确实出现在所录窗口中且无遮挡；不能只凭网页快照或窗口标题认定录对。实际录前预览不一致时先解决窗口映射，不能录另一个页面交付。保持录制期间窗口尺寸稳定。
2. 调用 `screenstudio_launch`，然后 `screenstudio_state` 与 `screenstudio_status`。状态非空先识别已有会话，不能结束或接管别人的录制；普通启动实例不能连接时遵循原技能正常退出重开的规则，不强杀。
3. 录制前调用 `screenstudio_sources`，依据当次应用名、窗口标题、位置和尺寸匹配目标 Ego 窗口。编号不能缓存、猜测或默认取第一个。若本镜只讲搜索框／输入区，优先选择包含必要上下文的局部；若需在多个面板间移动，录横屏窗口以便后期平移。不要因目标没找到就改录整屏。区域录制使用当次屏幕的 `displayId` 与 `area`，坐标为逻辑点，参数形状读当前工具说明，不猜。
4. 声音按用途决定：网页原声、音乐作品或声音功能演示明确需要声音时设 `systemAudio:true`；纯无声操作补画面可设 `false`。麦克风、摄像头仅按用户要求启用，设备编号来自当次来源。系统声音可能包含其他应用，应在录前排除无关声音；不能把“系统声音”当成已隔离的网页专用音轨。

## 录制与操作衔接

以下是 MCP 调用的参数形状，窗口编号必须替换为当次返回值，不是可照用的目标：

```js
// screenstudio_start
{windowId: CURRENT_EGO_WINDOW_ID, name: 'shot-01-take-01', systemAudio: false}
// screenstudio_control
{action: 'pause'} // 或 resume、addMarker、finish
```

`start` 只能指定 `windowId`、`displayId` 之一。等待返回 `state.type === 'recording'` 才开始 Ego 操作，先留剪辑余量，再依次定位、操作、核实真实响应、停留结果。原生录制使用当次窗口实际坐标与页面大小，不套用网页帧录制的虚拟尺寸覆盖。

动作失败时先保留现场与记录，不通过重绘成功状态修复。长等待可暂停，先确认已暂停；恢复后确认正在录制再操作并留接缝余量，不能在暂停期间执行并漏掉关键因果。需要剪辑定位时可用 `addMarker`，它不是成片文字标注。动作返回成功与录制状态是两种证据：页面结果仍需单独观察。

## 结束、声音与可播放交付

1. `finish` 后保存工程路径与返回的完整分段列表；须有 `verified:true`、非零时长和尺寸、实际可解码录像。必要时用 `screenstudio_verify({projectPath: ...})` 重查。错误若已说明工程保存路径，先 verify，不重复 finish。
2. 原工程保留鼠标轨迹等编辑数据，不能只留抽出的画面。`segments` 是原始录像，未包含编辑器里的自动缩放、背景与光标样式。不要据此声称完成了这些效果。
3. 单段且声音完整时可复制完整 MP4；只有播放清单和分片时先重新封装。暂停后的多段按 `metadata.json` 会话顺序核对并合并，不能按文件修改时间排序，不能交付初始化用的 `*-0000.mp4`。
4. 声音可能独立保存。检查 `audioTracks`、原工程时间信息和最终 MP4 的音轨；分段的 `audio:false` 不代表整个工程无声。独立轨道按元数据对齐，不猜从零开始，也不丢弃麦克风或系统声音。不同分段尺寸、编码或音轨结构不兼容时先处理兼容副本，保留原件；无法确认同步时保留工程并明确待处理，不能当无声成片交付。
5. 先按下节完成展示编辑，再按[执行与验收](execution.md)导出兼容成片。完整解码并在手机尺寸预览点击前后、推拉／平移中段和接缝；有声音时试听对应画面。录制器的画面验证不能代替构图、美术、声音和成片验收。
6. 保存完成后用 `quit` 正常退出并核对连接关闭；用户还要在编辑器继续工作时按其要求保留，不丢弃未保存更改。Ego 任务空间仍按自己的技能清理。

在镜头表或验收记录中留下 `captureBackend: "screenstudio"`、工程路径、录制目标、原生尺寸、帧率、分段顺序、实际音轨、交付文件和验证结果。来源列表、私人窗口标题及操作快照留在任务本地，不随技能包分发。

## 必做的展示编辑

1. 为本镜选择纯口播、纯录屏／右下小圆头像、上界面下本人各半；不要先套一个固定版式再找内容填。
2. 打开当前 Screen Studio 工程，核实实际编辑界面。优先使用软件可用的缩放、缩小、跟随和取景编辑：搜索框先放大居中，跨面板时横向移动，操作和结果处停住，需要时拉回概览。自动缩放以当前点击目标为线索，仍要检查它有没有放错地方、放不够大或超出安全区。
3. 保持界面原比例，在竖屏中央可读地展示当前重点；四周安全区与人像遮挡按[构图规则](framing-and-layout.md)检查。不要给每次鼠标细动都加一次放大，也不要用默认背景、圆角卡片和厚阴影替代构图。
4. 若当前适配器只提供录制方法，继续用实际编辑界面核实软件能力。接口缺方法不等于软件没有功能。若本机版本或界面确实无法完成所需运镜，保留原工程，用外层合成做等效推拉／平移并记录；不能因此退回整页小字、静态截图或未经处理的原始分段。
5. 交付的MP4必须实际包含安排好的镜头运动。不能把工程里的缩放标记，或未带编辑效果的原始分段，说成已完成 Screen Studio 动效。

## 本机验证记录

本机在 `3.5.1-4051` 验证了录制、暂停续录、结束和文件检查；另已在工程副本中通过原生编辑模型添加两段相接的2倍缩放、分别指定左右取景位置，用应用保存后确认 `project.json` 含两个缩放区间，并在原生播放中观察到放大、平移及返回全景。该测试证明本机可控制这些原生工程效果，尚未验证带样式导出或全部光标功能。

第3版测试使用场景的 `addZoomRange`／`updateZoomRange`，字段为 `startTime`、`endTime`、`zoom`、`type: "manual"`、`manualTargetPoint: {x,y}`；时间单位毫秒，取景坐标0～1。只能在核实当前版本、工程和数据结构后调用，先用副本测试，不能照搬第4版字段。保存后读回工程数据；暂停定位可能尚未更新完整预览，应在真实播放中检查镜头效果，不用黑色画布读取结果冒充画面验证。

不能把上游第4版接口未经核实地调用成本机第3版接口，也不能把这个限制解释成放弃缩放编辑。真实页面保持原色与正常布局、比例，最终展示以中央重点为主；不以整页全露出或额外卡片装饰作为完成标准。
