# 录屏原则

这些原则由 13 个参考视频的画面观察提炼；持续时间是本技能建议值，不是对原片精确运动参数的测量。

## 一段只教一个动作

先定义这一段结束时观众应知道什么。例如：“点开模型菜单，并看到可选项”，而非“把整个网站逛一遍”。

采用“定位 → 操作 → 响应 → 结果停留”顺序：

- 建立位置约 0.4–0.8 秒，光标先移到目标附近。
- 移动约 0.25–0.55 秒，到达后停 0.15–0.3 秒再点；点完给界面响应，不连点抢跑。
- 对关键结果停留约 0.8–1.6 秒，密集文字更久。按台词长度调整，读不完就删次要信息或延长镜头。
- 默认录制头尾各预留约 0.5 秒供剪辑。不把加载、失败重试和长时间寻找入口都放进成片。

依据：Oii Omni 约 25–28 秒从产品入口切到上传画布，约 64.5–66 秒只放大 Agent 模式；动作复制视频约 47–50 秒先指向深度提取，再展示选项。

## 保留上下文，再局部放大

先读[构图与口播组合](framing-and-layout.md)。录制范围与成片范围分开：真实横屏桌面界面可以录完整窗口，也可以用 Screen Studio 只录重点局部；输出竖屏不要求录制时把浏览器改成竖屏。界面布局、显示器比例和文字形状保持正常。

讲进入编辑器时先完整交代左右面板、预览和底部轨道，再连续推近重点；其它镜头只有需要交代位置时才短暂给软件概览，再突出按钮或结果；不要求每镜都从全页面开始。放大后保留足以识别位置的菜单、框体或关联内容。关注点在中央且字够大，比“整页全部露出”更重要；搜索框贴在最上面而看不清的全页录屏直接判不合格。

Screen Studio 的放大、缩小、跟随和平移应服务观看：先靠近目标、目标居中后操作、结果出现后停留，需要再拉回。跨面板操作可以横向移动同一横屏素材；不要将横屏拉高挤瘦，也不靠裁掉关键内容填满9:16。当前软件编辑能力要实查，接口未暴露时继续看实际编辑界面，或做保留原录屏的等效后期运镜，不能因此省掉重点展示。

四周给平台遮挡和字幕留余量，重点文字、控件、鼠标落点和人脸都在安全范围内。圆头像放在安全区内的右下方并避开操作；上下分屏是上界面、下本人各一半，不是两个 UI 区块堆叠。默认不新增标题或解释字幕，不把界面缩成大黑底中的小卡片。小字号无法读时先改取景或重录，不放大糊字充数。

## 光标与强调层各司其职

光标用于指路，框／环／短标签用于强调，最多一个重点。光标抵达后再出现强调；完成该步就撤掉。镜头跟随目标而不是追逐每次鼠标细动。录制器不保证捕获系统光标，若要补画光标，按动作日志坐标单独合成，保持点击位置与真实动作一致。

默认强调层不修改网页内容。若使用局部注入标注，限定为自己的视觉覆盖层并在结束清理；不要改 DOM 文本、数据、成功状态或隐藏真实错误。登录、验证码、权限选择交给用户，不录密码和授权密钥。

## 剪辑保留因果

录屏可以和说明动画结合，参考 [Rourke 的操作组织](rourke-study.md)：先确定当前控件，再实际操作；必要的高亮、放大、素材连接或结果揭示单独叠加。同一素材从输入贯穿到结果，界面响应仍以真实页面为准。不要把整段录屏缩成黑底上的小卡片，也不要用重建的成功状态填补失败步骤。

可以压缩等待，但保留“请求发出 → 等待的提示 → 真实结果”。对等待的跳切或加速在需要时写“等待已缩短”。不把失败状态接到另一任务的成功结果，不暗示画面中没有执行过的动作。

跨段接力时统一窗口边界、缩放中心、裁切与必要短标识的位置。不要把缩放、滚动、鼠标飞行、字幕跳动同时叠在一个动作上。对比用同位置、等比例、对应帧与扫描揭示；确需标识时用简短的“修改前／修改后”，不要求两边并排，也不堆解释。像素／色彩处理一致。

## 先排练再录

在当前登录态打开页面，核实目标真实存在；用快照选择目标。先写这一镜强调人还是界面、主要取景和镜头落点，再排练。可撤销操作先走一遍；可能产生费用、发布或外部消息的动作遵守用户授权范围。排练后确认回到起始状态，再录短段。返回或重置会损坏用户内容时不要强行重置，改为录安全步骤。

## 可用性标准

在手机观看尺寸检查首尾、点击前后、平移中段和结果稳定帧：能否一眼找到当前目标，搜索词／修改点能否直接读出，界面比例是否正常，重点是否仍在中央安全区，头像是否挡操作，上下分屏是否确为界面＋本人。实际操作与台词一致，无个人通知或无关弹窗。

再检查技术文件。输出报告区分“捕获帧的真实频率”和“导出容器标注30fps”；后者不会使低频录制自然变流畅。快滚动或动画页面采样不足时重录重点局部、减慢镜头或采用当前环境可用的原生窗口录制；降低捕获尺寸不能让关键字变糊。不要用重复截图伪称高帧率录屏，也不能以“可播放、无黑帧”替代上述构图检查。

下载网页中的参考视频时，部分平台把音频与画面分开加载。取得可播放画面地址后仍要检查音轨；必要时分别保存原始视频流与音频流，用无损封装合并，再交付兼容副本。浏览器里听得到声音不等于下载文件已经有声音。

搜索、多列滚动、原位圆角高亮、完整提示词卡片、实际键入与倍速生成过程，按[连续录屏与提示词展示](continuous-screen-direction.md)执行。
