# 参考效果重建

适用于用户给成片，要求拆解、反推提示词、做类似动效或改变画幅的任务。案例入口见[近期案例库](recent-examples.md)。

## 先分清参考与输入

- 原成片、裁出的案例、本地联系图与拆帧，默认只供助手观察和分析。观看、下载或裁剪授权不等于上传到生成平台的授权。
- “复刻”“参考这个视频”“全能参考”不自动授权原视频输入。未经用户当次明确指定，不把原片、原片拆帧、原音频输入生图或视频模型，也不换个平台绕过这一边界。
- 根据文字重新生成产品、角色、道具、场景，或复用用户当前已授权的独立资产；先确认外形和身份。新任务不直接沿用样例品牌、资产或人物。
- 关键帧需要时用 imagegen，输入新资产与文字构图描述；不输入原片截图。优先使用生成叠加次数少的资产。已生成的完整镜头默认用于本地审美确认；用户指定用关键帧控制时才按其范围输入视频模型。

## 从看到的动作写成时间线

先核对时长、尺寸、画幅、帧率，再在本地看总览、各段首尾及过渡区间。总览用于找画面组，切点附近密集观察，避免按平均时长猜分段。

把以下内容转成文字，后续生成不依赖模型观看原片：

| 观察项 | 写成可执行的描述 |
|---|---|
| 主体与构图 | 数量、比例、位置、朝向、完整／出画范围、前后关系与落点 |
| 动作 | 谁从哪里进入、沿什么路径移动／翻转、何时减速、何时停留 |
| 层级 | 前景、主体、背景分别怎样动；遮挡由哪层承担 |
| 转场 | 前一画面结束状态、可见遮挡物、切换时刻、后一画面的出现方式 |
| 文字 | 原文、字号层级、字体类别、入场顺序、可读停留与退出时刻 |
| 美术 | 光线、颜色、材质、投影、细节密度和留白；不要只抄色板 |
| 声音 | 区分教程讲解、案例声音与用户需要的音效；明确是否需要音乐和人声 |

每个连续阶段先有一个主要动作，再写运镜和结束状态。把物件运动与整幅画面平移区分开，不以四张图片轮播替代重建。图形排版需要准确文字和严格切点时，可用已有新资产做可编辑动效；用户已指定生成模型时保留其选择并说明控制范围。

## 新资产应能单独引用

先按产品、角色、道具、场景拆清职责。资产总览可以用于检查风格，但多个独立物件通常分别保存、分别引用，避免模型把整张资产表排版一起带入画面。

- 用户要求“拆开”时，优先无损裁出已有的新生成物件，保留原外形；不要为了拆图重新设计。裁图不等于抠出透明底，也不等于增加细节或达到 2K。
- 需要重画或独立高清资产时，从原始授权资产或文字重新生成，减少连续修改；读实际像素后再报告尺寸。
- 使用同一产品跨镜头时，包装文字、图案、结构与比例共同锁定；只重复产品名不能保证身份一致。
- 一张图只承担明确职责，提示词分别引用。不要把观察用联系图、参考截图混在可上传素材目录中。

## 提交前核对真实引用

按当前模型能力保存方案后回读：图片／视频／音频输入计数、每份来源、文字中引用位置、上游关系、分辨率、时长、画幅、条数与原生声音设置。仅新图片方案要确认视频为 0、音频为 0，且没有通过其他节点间接带入原片。

留一份用户可读的输入清单。观察文件与可提交文件分开放，不能用“提示词说了不要参考视频”代替检查真实输入。价格按当前保存方案重新查询；示例历史报价不是未来价格或费用授权。等待时沿用同一任务标识，不因超时重提。

## 出片后保留差异

按[独立复检](post-render-review.md)检查实际文件，并分别记录：素材外形、包装图案、主要文字、物件运动、遮挡关系、实测切点、结尾、声音与文件规格。模型可能自行朗读画面标题，提示词时间点也可能偏移；不能因没有音频输入就声称没有人声。

保留生成原片和原声；不擅自静音、替换或后配音效。不能精确复现的部分记录到具体时刻，新增付费修订按已有授权边界执行。用户对美术方向的认可和“各项完全通过”分别记录，不能互相替代。
